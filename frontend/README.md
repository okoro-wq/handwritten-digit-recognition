# Frontend — Handwritten Digit Recognition

React + TypeScript + Vite + Tailwind CSS client. Draws a digit on a canvas and sends it to the
FastAPI backend for prediction.

See the [root README](../README.md) for the full project overview and setup instructions.

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — type-check and build for production
- `npm run lint` — run ESLint
- `npm run preview` — preview the production build locally
